# 论文全稿审查

模拟中文经济学顶级期刊审稿人，对学术论文进行全面、建设性的审查——产出一份顶刊审稿人水准的审稿报告。

此技能为**只读**。可生成参考文献验证报告并推荐修正方案，但不直接修改论文或参考文献文件。直接修改属于 `revise-paper` 技能的职责。

**输入：** `$ARGUMENTS` — 论文路径（.tex、.pdf 或 .qmd），或 `master_supporting_docs/` 中的文件名。

---

## 步骤

1. **定位并读取论文。** 检查：
   - `$ARGUMENTS` 给出的直接路径
   - `master_supporting_docs/supporting_papers/$ARGUMENTS`
   - 模糊匹配（glob）

2. **通读全文。** 对于长篇 PDF，分块阅读（每次5页）。

3. **按6个维度评估**（见下文）。

4. **执行 CNKI/Crossref 双通道参考文献验证**（若论文为 .tex 或 .qmd 源文件且可获取参考文献数据）。

5. **生成 3-5 个"审稿人质疑"** — 顶刊审稿人会提出的尖锐问题。

6. **产出审查报告。**

7. **保存至** `quality_reports/paper_review_[简化名称].md`

8. **如发现参考文献问题，另存专项文献核查日志** 至 `quality_reports/literature_verification_YYYY-MM-DD.md`。

---

## 审查维度

### 1. 论证结构
- 研究问题是否清晰明确？
- 引言是否有效地提出问题动机？是否遵循"现实动机→学术争论→本文切入"三段递进？
- 逻辑链条是否完整（问题→方法→结果→结论）？
- 结论是否有证据支撑？是否存在过度推论？
- 是否承认研究局限性？
- 边际贡献是否从"本文区别于既有研究的边际贡献在于以下几方面"格式清晰阐述？

### 2. 识别策略
- 因果推断是否可信？
- 核心识别假设是什么？是否明确陈述？
- 是否存在内生性威胁（遗漏变量、反向因果、测量误差）？
- 稳健性检验是否充分？是否涵盖替换变量、替换样本、替换估计方法？
- 估计方法是否适合研究设计？
- 工具变量的排他性和相关性论证是否严谨？

### 3. 计量设定
- 标准误处理是否正确（聚类？稳健？Bootstrap？）？
- 函数形式是否恰当？
- 是否存在样本选择问题？
- 是否关注经济显著性（而非仅统计显著性）？
- 估计系数的量级是否合理可解释？
- 异质性分析是否有理论支撑而非数据挖掘？

### 4. 文献定位
- 是否引用了领域内的关键文献？
- 对前人工作的描述是否准确公允？
- 本文贡献与既有工作的区别是否清晰？
- 是否有审稿人会指出的遗漏引用？
- 中文文献与英文文献的比例是否合理（建议各占40-60%）？
- 文献综述是否按主题/争论组织而非简单罗列？

若源文件为可编辑文本，还需使用下方的参考文献验证协议检查引用条目的准确性。

### 5. 写作质量
- 语言是否符合中文学术规范？（参照 `chinese-top-journal-style.md`）
- 是否使用"本文""研究发现""实证表明"等学术用语？
- 术语使用是否前后一致？
- 内容提要是否有效概括全文（300-500字）？
- 图表是否自含（标题完整、注释清晰、数据来源注明）？
- 脚注是否使用圈码序号（①②③）？

### 6. 呈现规范
- 表格是否符合三线表规范？
- 全文符号体系是否前后一致？
- 是否存在错别字、语法错误、格式问题？
- 篇幅是否适合贡献量（中文顶刊通常 1.5-2 万字）？
- 章节编号是否遵循"一、二、三…"→"（一）（二）（三）…"→"1. 2. 3."层级？

## 审查原则

- **建设性为先。** 每一条批评都应附带修改建议。
- **具体明确。** 引用具体章节、公式、表格。
- **以顶刊审稿人思维审视。** 什么会导致退稿？
- **区分致命缺陷与小问题。** 并非所有问题同等重要。
- **肯定做得好的地方。** 优秀研究值得认可。
- **不捏造细节。** 如无法清晰阅读某部分，如实说明。
- **兼顾中文顶刊特色。** 参照 `chinese-top-journal-style.md` 中的规范。

## 参考文献验证协议（CNKI + Crossref 双通道，只读）

审查 `.tex` 或 `.qmd` 论文的参考文献条目准确性。

### 目标

识别不准确的参考文献条目。常见问题包括：

- 标题错误或截断
- 作者姓名列表错误
- 年份错误
- 期刊名、卷期页码错误
- 工作论文/即将发表的引用已正式出版
- 混合版本引用（工作论文标题 + 正式发表的期刊信息）

### 步骤1：识别参考文献来源

1. 检测论文使用的参考文献格式：
   - 外部 `.bib` 文件
   - 内联 `thebibliography`
2. 提取参考文献条目和引用键。
3. 在正文中 grep `\cite`、`\citet`、`\citep`、`\citeauthor`、`\citeyear`，确定实际被引用的条目。
4. 优先验证被引条目。未被引条目可单独列出。

### 步骤2：分通道查询

**中文文献** → CNKI（知网）通道：
- 使用 `fetch_webpage` 查询 CNKI 学术搜索
- 按篇名+第一作者查询
- 核对期刊名、年份、卷期页码

**英文文献** → Crossref 通道：
- 查询模式：
  ```text
  https://api.crossref.org/works?query.title=PAPER%20TITLE&rows=10
  https://api.crossref.org/works?query.author=AUTHOR%20SURNAME&query.title=PAPER%20TITLE&rows=10
  ```
- 使用 `fetch_webpage` 获取元数据

### 步骤3：比对核验

将参考文献条目与官方元数据比对：

| 字段 | 核验内容 |
|------|---------|
| 标题 | 是否为最终发表版标题 |
| 作者 | 姓名列表是否完整正确 |
| 年份 | 是否与引用版本一致 |
| 期刊 | 期刊名/书名是否匹配 |
| 卷期页码 | 是否正确 |
| 状态 | 工作论文/即将发表是否已正式出版 |
| 版本一致性 | 是否存在工作论文标题+已发表期刊信息的混合 |

### 步骤4：官方来源兜底

若 CNKI/Crossref 不完整或有歧义，按以下顺序核实：

1. 期刊官网或出版社页面
2. NBER 页面（工作论文）
3. 大学出版社页面（书章节）
4. 机构知识库页面

### 步骤5：报告规则

创建或更新：
```text
quality_reports/literature_verification_YYYY-MM-DD.md
```

分类标记：
- `✅ 核实无误`
- `⚠️ 需实质性修正`
- `ℹ️ 仅需引用键清理`
- `🔍 需人工核实`

对每个问题条目记录：
1. 当前参考文献文本或有缺陷的字段
2. 查到的官方元数据
3. 建议的修正引用
4. 当前引用的是工作论文版、正式发表版、还是混合版
