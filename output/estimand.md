# 因果识别目标与设定 (Estimand & Identification Strategy)

> 本文件基于合成面板数据 `data/raw/digital_transformation_firm_panel.csv` 明确 DID 研究的识别目标。
> 面板结构：360 家企业 × 9 年（2016–2024），共 3,240 个观测，无缺失值。
> 注意：数据为教学演示用合成数据，不构成对真实文献的因果推断。

## 1. 处理组 / 对照组定义

| 分组 | 定义（数据规则） | 样本量 |
| :--- | :--- | :--- |
| **处理组 (Treated)** | `adoption_year == 2020` 的企业，即样本期内（2020 年）开始实施数字化转型，`treated == 1` | 151 家企业（1,359 个观测） |
| **对照组 (Control)** | `adoption_year == 9999` 的企业，即整个样本期内从未实施数字化转型，`treated == 0` | 209 家企业（1,881 个观测） |

- 处理变量 `digital` 由分组与时点交互生成：`digital = treated × post`，其中 `post = 1(year ≥ 2020)`。
- 分组变量与处理变量在面板内不随时间变化的部分吸收于企业固定效应，识别来源完全依赖处理组在 2020 年前后的相对变化（即 `digital` 的组内变异）。

## 2. 统一处理时点（2020）

- 所有处理组企业统一于 **2020 年**（`post` 从 0 跃迁为 1）开始实施数字化转型，属于**单期统一处理时点（Standard Non-staggered / 2×2 DID）**，不存在交错处理（staggered adoption）。
- 因此不存在因交错处理导致的异质性处理效应偏误（如负权重、Bacon 分解问题），传统 TWFE 估计量即为干净的处理组平均处理效应。

## 3. 目标估计量：ATT

- 目标参数为**处理组平均处理效应（ATT, Average Treatment Effect on the Treated）**：

$$
\text{ATT} = \mathbb{E}\big[\,Y_{it}(1) - Y_{it}(0) \mid \text{Treated}_i,\ t \geq 2020\,\big]
$$

- 实现上由双向固定效应（TWFE）回归估计：

$$
\log TFP_{it} = \alpha_i + \lambda_t + \beta \cdot digital_{it} + \gamma X_{it} + \varepsilon_{it}
$$

其中 $\alpha_i$、$\lambda_t$ 分别为企业与年份固定效应，$X_{it}$ 为时变协变量（资本密集度、出口占比、所有制），$\beta$ 即 ATT 的点估计。

## 4. 关键识别假设

| 假设 | 含义与检验 |
| :--- | :--- |
| **平行趋势假设 (Parallel Trends)** | 若无数字化转型，处理组与对照组企业的 $\log TFP$ 时间趋势应一致。检验：事件研究（event study）中处理前各期（2016–2019）系数应统计不显著、接近 0。 |
| **无预期效应 (No Anticipation)** | 企业在 2020 年实施转型前未因预期而提前调整生产行为。若成立，处理前各期系数为 0。 |
| **个体处理稳定性假设 (SUTVA)** | 企业间不存在溢出/一般均衡效应（无干扰），且"数字化转型"对每家处理组企业定义明确、处理状态唯一。 |
| **模型设定正确** | 控制企业/年份固定效应与主要协变量后，处理变量与潜在结果条件独立（条件外生性）。 |

## 5. 核心识别威胁

1. **选择性偏差与时变冲击（非平行趋势）**：高能力企业或特定行业/地区的企业更可能率先数字化转型，若其增长趋势与对照组不同，则 $\beta$ 混入选择效应与宏观趋势，高估或低估 ATT。
2. **测量偏误**：0/1 虚拟变量仅捕捉"是否转型"，忽略转型深度、强度与质量的异质性；`digital` 的测度误差可能导致衰减偏误。
3. **组内/组间相关性与聚类标准误**：面板自相关及行业、地区层面的相关性使普通标准误低估显著性，故回归采用**企业层面聚类稳健标准误**。
4. **协变量在 2020 年前后的内生变动**：若企业为转型而改变资本/出口/所有制结构（对处理的内生响应），控制这些"坏控制"会引入偏误；此处以演示为主，未做坏控制调整。
5. **合成数据的外部有效性**：参数设定来自数据生成过程，结论仅具教学演示意义，不可外推至真实企业。
