# 识别目标（Estimand）与因果设定

| 项目 | 我的回答 |
|:---|:---|
| 处理组 / 对照组 | 处理组：2020 年开始实施数字化转型的企业；对照组：样本期内从未转型的企业 |
| 处理时间 | 2020 年（统一处理时点，非交错 DID） |
| 目标估计量 | 处理组平均处理效应（ATT） |
| 关键识别假设 | 1. 平行趋势假设（若无数字化转型，两组企业 TFP 的演变趋势一致）；<br>2. 无预期效应（政策实施前企业无提前反应）；<br>3. 稳定个体处理效应假定（SUTVA，不存在企业间溢出效应） |
| 主要威胁 | 1. 行业与区域层面的时变未观测宏观冲击（竞争性假说）；<br>2. 企业规模与初始管理能力导致的自选择偏差；<br>3. 极端值扰动与变量测量误差 |
