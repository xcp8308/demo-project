# DID 稳健性综合评估报告

## 1. 主结果
- **DID 系数**：0.121
- **聚类标准误**：0.005（聚类到企业层面）
- **显著性**：p < 0.01

## 2. 稳健性判定表
| 检验 | 判定（通过/警示/失败） | 依据 |
|:---|:---|:---|
| R1 平行趋势 | 通过 | 处理前系数联合检验 p=0.312，未见前置趋势。 |
| R2 安慰剂检验 | 通过 | 伪估计均值极小（0.001），真实效应 0.121 远超随机分布。 |
| R3 替换结果变量 | 通过 | 劳动生产率结果（0.118）与 TFP 一致。 |
| R4 控制变量集合 | 通过 | 增减控制变量时，系数稳定在 0.119~0.125 之间。 |
| R5 改变聚类层级 | 警示 | 二维聚类（firm+year）下标准误从 0.005 扩大至 0.011，但维持 5% 显著水平。 |
| R6/R7 样本与极端值 | 通过 | 缩尾和样本修剪后，系数稳定在 0.115~0.126，无极端驱动。 |
| T1-T4 机制与异质性 | 通过 | 强度的边际效应显著；互补机制（T3）得到验证；排除行业冲击（T4）。 |

## 3. 结论稳定性
本研究的核心主效应具有极高的稳定性。无论是在常规的估计量替换、聚类惩罚，还是样本裁切下，处理组平均处理效应（ATT）始终维持在 0.115~0.126 之间且保持显著。结论不依赖于特定的控制变量组合。

## 4. 残余威胁
结合主题，当前实证框架仍有以下威胁未能彻底排除：
1. **遗漏的可变不可观测特征**：虽然控制了 `industry × year`（T4），但如果企业内部管理模式恰好在 2020 年发生了其他未观测的系统性变革（且与数字化同时发生），这种“不可观测的动态能力冲击”无法被 FE 完全吸收。
2. **测度误差**：数字化强度（T1）由模型估算而来，真实的数字化投入金额和技术资产累积仍是“黑箱”。

## 5. 主题解读
数字化转型并非简单的“即插即用”，其提振 TFP 的效应具有显著的条件约束。机制检验（T3）中的交互项显著（系数 0.102）强有力地说明：**高管理能力是数字化红利变现的必要互补资产**。异质性（T2）显示大型企业获益更多（0.145 vs 0.042），暗示了数字化转型存在较高的资金和沉没成本门槛。

## 6. 对论文写作的建议
- **能写什么**：在正文中大胆宣称基准回归结果通过了极其严格的平行趋势与安慰剂测试。重点讨论 T2 和 T3，强调“数字-管理双轮驱动”的理论贡献。
- **不能写什么**：在表述因果关系时保持克制，使用“提升效应”、“边际改善”等词，**切忌**使用“只要数字化就能无条件提高生产率”等决定论表述。必须在局限性小节诚实汇报 R5 导致的置信区间适度扩大，以及 S4 提到的不可观测动态冲击风险。
